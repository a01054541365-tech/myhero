# TASK P2: 밸런스·보안 수정

> 우선순위: 🔴 높음 (1단계 — HOTFIX 완료 후 시작, P1과 병렬 가능)  
> 소스셋: main  
> 완료 기준: `./gradlew compileJava` 성공

---

## 의존 관계

- **선행 필수:** HOTFIX 완료
- **P1과 병렬 가능**

---

## 수정 항목

### 1. 속박파훼 (Binding Void Break)
- 속박 해제 로직 수정
- `sealDurationTicks = 600틱` §LOCK 값 유지

### 2. RTT 클램프 (Round-Trip Time Clamp)
- 클라이언트 RTT 기반 입력 처리 시 상한 적용
- 클라이언트 측 수치 신뢰 금지 원칙 준수

### 3. 하카리 (Hakari) 상한
- 하카리 잭팟 데미지 상한 적용
- `잭팟 기본값 상한 = 251틱` §LOCK 값 유지

### 4. 이누마키 (Inumaki) 채팅 제한
- 이누마키 스킬 발동 시 채팅 제한 구현
- 서버 권위로 처리 (클라이언트 신뢰 금지)

### 5. 제재 시스템
- 어뷰징/핵 감지 시 제재 처리 로직
- 서버 사이드 검증 강화

---

## 보안 원칙 준수
- 클라이언트가 보낸 데미지·명중·쿨타임 값 신뢰 금지
- 모든 검증은 서버에서 수행

## 검증
```
./gradlew compileJava
각 수정 항목별 동작 테스트
§LOCK 수치 변경 없음 확인
```
