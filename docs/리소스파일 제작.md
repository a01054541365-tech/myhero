각 엔티티별 필수 애니메이션

무키 (muki.animation.json)

애니메이션 이름루프 여부길이(초)핵심 동작animation.muki.idleloop2.0몸통 상하로 0.2블록 부유, 팔 흔들animation.muki.walkloop1.0팔 앞뒤 스윙, 몸 앞으로 기울임animation.muki.attackonce0.6팔을 앞으로 뻗는 동작animation.muki.deathonce1.0몸 아래로 가라앉으며 소멸

코츠바쿠 (kotsibaku.animation.json)

이름루프길이동작animation.kotsibaku.idleloop2.5뼈 덜그럭 소리 느낌, 몸 약간 떨림animation.kotsibaku.walkloop0.8해골 걷기animation.kotsibaku.throwonce0.8팔을 뒤로 당겼다가 앞으로 던지기animation.kotsibaku.deathonce1.0해체되며 무너지는 동작

호무라쿠이 (homuraku.animation.json)

이름루프길이동작animation.homuraku.idleloop1.5배 부풀어오름, 등 돌기에서 불꽃animation.homuraku.walkloop0.9둔중한 걷기, 땅 흔들림 느낌animation.homuraku.attackonce0.7앞으로 돌진하는 동작animation.homuraku.explode\_warnonce3.0전체적으로 부풀어오름 + 떨림 (자폭 경고)animation.homuraku.deathonce0.5빠르게 수축 후 터지는 동작

죠고 NPC (jogo.animation.json)

이름루프길이동작animation.jogo.idleloop2.0화산구 연기 느낌, 팔 교차animation.jogo.walkloop0.9위엄있는 걷기animation.jogo.attack\_meleeonce0.6주먹 내려치기animation.jogo.deathonce1.5무릎 꿇고 쓰러지기

이에이리 / 공시우 / 이치지 NPC

각각 idle(loop, 2.0s) + talk(loop, 1.0s, 고개 끄덕임) 2개씩 제작.



Blockbench 애니메이션 제작 핵심 규칙

Pivot 설정

각 뼈의 Pivot Point를 정확히 관절 위치에 맞출 것.

팔의 Pivot → 어깨 위치 / 다리의 Pivot → 골반 위치.

잘못 설정 시 회전이 비정상적으로 보임.

키프레임 최소 원칙

불필요한 키프레임을 줄일 것. idle 애니메이션은 키프레임 4\~6개로 충분.

과도한 키프레임 → 파일 크기 증가 → 로딩 느려짐.

Loop vs Once 구분



loop: idle, walk처럼 반복되는 동작

once: 공격, 사망처럼 1회성 동작 (종료 후 idle로 복귀)



GeckoLib 애니메이션 컨트롤러 연동 확인

Java 코드의 registerControllers()에서 애니메이션 이름이 정확히 일치해야 함.

예: new RawAnimation.begin().thenLoop("animation.muki.idle")

OGG 변환 방법 (Audacity)

1\. Audacity 실행 → 원하는 소리 파일 불러오기 (또는 직접 녹음)

2\. Effect → Normalize (-3dB로 음량 정규화)

3\. File → Export → Export as OGG Vorbis

4\. Quality: 5 (표준. 너무 높으면 파일 크기 과다)

5\. 저장
