# JJK 서버 — 05. 연출·이펙트 가이드 (참고용)

> ⚠️ \*\*이 파일은 구현 명세가 아니다.\*\* VFX·SFX·애니메이션 연출의 방향성을 정리한 참고 문서다.
> Claude Code에 구현을 지시할 때 이 파일을 컨텍스트에 포함하지 않는다.
> 클라이언트 사이드 작업 시에만 참조한다.

\---

## 1\. 공통 전투 연출

### 1-1. 흑섬 (Black Flash) — animId 9, 56

VFX: 타격 순간 화면 전체 흑백 반전(0.1초). 타격 지점에서 검은색+붉은색 번개 파티클 방사.
SFX: 공간 왜곡 저음 폭발음 (Bass Drop).
Camera: 강한 화면 흔들림. 0.1초 Hit Stop.

### 1-2. Zone 진입 — animId 58

VFX: 플레이어 눈 위치에서 푸른 안광 파티클 Trail.
SFX: 심장박동 페이드인.

### 1-3. 각성 진입 — animId 57

VFX: 발밑 기류 파티클, 주변 3블록 내 파티클 부양.
SFX: 이명 + 폭발적 기합.

### 1-4. Just Frame 피드백

UI/VFX: 크로스헤어 주변 순간 발광 또는 손끝 스파크.
SFX: 날카로운 타격음.

\---

## 2\. 캐릭터별 스킬 연출

### 2-1. 고죠 사토루

창(Blue) F: 공간 왜곡 구체, 잔상 Motion Blur.
혁(Red) Shift+F: 붉은 구체 응축 → 충격파 링.
허식 자(Purple) R: 창+혁 파티클 융합 보라색 구체. FOV 왜곡.
무하한 토글 V: 공격 방어 시 육각형 반투명 방어막.

### 2-2. 이타도리 유지

경정권 F: 1타 일반 파티클 → 5틱 후 2타 푸른 주력 폭발.
맨지 킥 Shift+F: 발끝 반원 궤적 Trail.

### 2-3. 후시구로 메구미

식신 소환: 바닥 그림자 확장 → 식신 솟아오름 (GeckoLib 애니 연계).
그림자 이동 V: 그림자 속으로 가라앉음 → 목표 지점 솟아오름.

### 2-4. 옷코츠 유타

리카 소환 F: 등 뒤 검은색/보라색 오라 + 리카 등장.
주력해방 Shift+R: 전신 핑크빛 오라, 이동 시 잔상.

### 2-5. 마히토

무위전변 F: 대상 모델 일그러짐 셰이더, 기괴한 효과음.
다중혼 Shift+F: 투사체가 울부짖는 얼굴 형태.

## 3\. 영역 전개 연출

공통 시퀀스 (animId 7, 8):

1. 수인 결성 애니메이션
2. 0.5초 암전
3. 영역 고유 셰이더/스카이박스 전환
4. "영역 전개" 보이스 + 굉음

캐릭터별:

* 무량공처: 우주/심연 스카이박스, 정보 매트릭스 파티클
* 스쿠나 복마어주자: 신전 모델 솟아오름, 바닥 핏빛 데칼, 참격 궤적
* 마히토 자폐원돈과: 거대한 손 돔, 늪 텍스처 바닥

## 4\. 기타 시스템 연출

### 4-1. 장막

VFX: 하늘에서 검은 반투명 돔이 천천히 내려옴. 내부 하늘 암흑, 조명 감소.

### 4-2. 히구루마 재판

VFX: 대상·히구루마 주변 법정 환영. 판결 시 머리 위 텍스트 파티클.
처형검: 하늘에서 빛나는 검이 떨어져 히구루마 손에 쥐어짐.

### 4-3. 사망·부활 — animId 5, 6

사망: 주력이 흩어지며 재가 되는 파티클.
부활: 주력이 모여들며 형체를 갖추는 역재생 파티클.

\---

## 5\. 클라이언트 구현 시 주의사항

* 파티클 생성량은 클라이언트 config에서 조절 가능하도록 옵션 제공.
* S2C 패킷 수신 즉시 이펙트 재생 (딜레이 최소화).
* 복잡한 모델(영역, 식신)은 AzureLib, 캐릭터 모션은 PlayerAnimator 활용.
* 모든 렌더링 코드는 `EnvType.CLIENT` 분기 또는 client 소스셋으로 격리.

\---

## 6\. 확장 제안 (미확정, 구현 우선순위 낮음)

아래 항목은 기획 단계의 제안이며 현재 명세에 포함되지 않는다.

* 환경 상호작용 이펙트 (블록 가상 파괴, 유체 반응, 식물 흔들림)
* 피격 종류별 차별화 (일반/치명타/영혼 데미지/가드)
* UI/HUD 동적 연출 (CE 게이지, 쿨타임 원형 표시, 데미지 폰트)
* 날씨/시간 연동 이펙트
* 주구(Cursed Tools) 시스템
* 주력 조작 범용 시스템
* 협동 레이드 콘텐츠
* 모듈형 스킬 시스템 (JSON 기반 컴포넌트)
* 인게임 디버그 UI (/jj debug 확장)
* 성능 프로파일러
* 패킷 암호화/행동 패턴 분석 안티치트
